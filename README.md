# Project Cinder

> 一款经典街机赛车游戏的安卓启动器与运行环境。

Project Cinder 把街机厅的赛车体验搬到手机上——不是模拟器，也不是串流。启动器、资源管线、渲染与输入层都是为 Android 重写的，游戏本体跑在本项目自研的 ARM64 运行时上。

游戏数据由你自己提供。Cinder 在本机完成导入、校验和运行，不附带、也不下载任何游戏资源。

## 项目状态

正在开发中。目前发布的是测试版本，线上服务已经可用，但仍在调整。

- 单人、计时赛、幽灵车对战都能完整跑通。
- 部分光影与特效是近似实现，不是逐像素还原。
- 不同机型差异明显，中低端机仍在调优。
- 每个版本发布前都会在真机上跑过，但这不代表你手上那台一定没问题。

遇到问题请提 issue，附上机型、系统版本和当时的操作。

## 主要特性

**启动器**

- 横屏启动界面，显式确认后才进入游戏，不会自动启动。
- 支持从 ZIP 或目录导入你自己的游戏数据，在手机上完成转换。
- 转换结果先校验再启用，并且是原子替换的。
- 资源包、车库存档、计时成绩、化身记录各自独立：清资源不会清存档。

**驾驶**

- ARM64 原生运行时，Vulkan 与 GLES 两条渲染路径。
- 固定 60Hz 步进，掉帧不会改变车辆的实际行为。
- 触屏、重力感应、外接手柄，键位可按设备单独配置。
- 引擎音效、BGM、赛道光照。

**联网**

- 每次安装生成独立设备 ID，在网页上一步完成授权。
- 计时赛排行榜，一条赛道一份榜单。
- 店内鬼王：每张图一位，跑赢就顶替。
- 化身分享：上传自己的录像，下载别人的化身当对手车。

## 线上服务

| 服务 | 说明 |
| --- | --- |
| 设备授权 | 登记设备 ID，立即生效 |
| 计时赛榜 | 每赛道每位车手一条最快成绩 |
| 店内鬼王 | 每赛道现任鬼王，跑赢即交替 |
| 化身仓库 | 上传与下载化身容器 |

服务地址：<https://niceapi.net>

榜单是社区榜。服务端只校验成绩格式与规则一致性，尚未做回放核验，页面上也如实标注了这一点。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| `ports/android/` | 当前 Android 开发源码：启动器、运行时、云端服务 |
| `ports/ipad/` | 早期 iOS 实验移植 |
| `src/` | 运行时与游戏逻辑 |
| `tools/` | 资源转换、数据提取与构建工具 |
| `android/` | Android 打包工程 |
| `docs/` | 设计与验证文档 |
| `build_android.sh` | 构建入口 |

各平台目录是各自的开发源码，不应互相覆盖。根目录保留上游基线。

## 构建

依赖：

- Android SDK 36 与 build-tools 36
- NDK 28
- JDK 17 或更新版本（推荐）
- Python 3.11+

构建需要显式提供签名 keystore、资源基准清单和运行时包。构建过程本身不会安装或上传任何东西。

部分由游戏数据生成的文件没有提交到仓库。全新的 checkout 在本地生成这些文件之前无法编译。平台目录的详细说明见 [`ports/android/README.md`](ports/android/README.md)。
