# Android 1.35：原版街机资源本地转换

这是开发候选功能，不是 Android 实机验收报告。APK 不附带原版游戏资源，也不提供资源下载。

## 使用

1. 不卸载旧版、不清除应用数据，安装同一签名的 1.35 候选包；Vulkan 与 OpenGL 二选一。独立存档沿用原位置。
2. 启动页点击“原版一键转换”，确认材料使用权，再在系统选择器选择原版 ZIP 或含 `main` 和 `data` 的原版目录。原版目录不能走“导入 / 修复”；后者保留旧运行 ZIP/旧直装 APK 的导入规则。
3. 程序只读来源、核对整套受审文件并制作私有只读快照，然后在后台转换。不要修改来源；建议接电并让应用保持前台、屏幕开启。后台服务不等于操作系统绝不休眠/回收，未在设备上验证长任务。
4. 所有 1,798 项输出均通过完整性及相应格式验证后，主进程再复制到新安装目录、重新校验，最后原子切换资源选择。界面确认就绪后再手动点“开始游戏”，不会自动启动。
5. 取消、失败或进程中断不会把 partial 资源启用；旧资源、未知文件、原始材料及独立存档不主动覆盖或删除。取消可能等待文档提供方返回，不承诺瞬停。失败暂存保留，可能继续占空间；不要为绕过错误而清除应用数据。

## 支持与容量

- 当前只接受已审的原版版本：`main` 为 24,855,892 字节，SHA-256 `2e6591153d7e599437465f736a42e27b01a3b56c881bee58365fb21d0678b1f6`。不同版本、缺项、变更、路径别名或不安全压缩包均拒绝，不尝试拼凑。
- 来源闭包共 **13,360 文件、3,642,480,523 字节**；不代表会收录或执行目录中所有文件。只复制受审来源，不运行原版 ELF/构造器，也不执行所选 APK。
- ZIP 上限 **8 GiB**；加密 ZIP、不支持的格式/标记、重复路径、路径穿越及超预算内容拒绝。多层包装目录的定位也有深度与数量限制，最好直接选最内层 `main+data` 目录。
- 准入要求设备非 low-RAM/low-memory 且当时至少 **2 GiB 可用内存**，不是“总内存 2GB 就够”。东京场景已见约 1.30GiB 主机中间峰值，设备内存需求及系统回收行为仍需实测。
- 须同时容纳来源暂存、只读快照、转换结果、最终安装副本及旧资源。建议预留 **20GB 或更多可用空间**；界面的瞬时准入估算、连续空间检查并非存储配额或完成保证，ZIP 实际体积和所在分区会影响需求。
- 转换是长任务，可能需要数小时；服务默认期限 4 小时，并遵守系统前台服务限制。不能把主机速度直接当成手机耗时。

## 信任边界

新原版通道是“APK 固定来源指纹 + 受控私有 job + 全来源快照 + 固定转换算法 + 输出格式/名单闭包 + 私有完成记录”。主进程只读取该 job 的固定完成位置，不接受服务消息里的任意 report 路径作为发布授权。

后续安装 HMAC 用于保护这次受控结果免遭后篡改，**不是外部玩家资源扫描后自签 DMF**。原有两个受审运行清单、41 项可选资源、旧 pending 恢复及存档保护规则不放宽。可选卡片/演出缺失不会从未知旧文件回退；新媒体重编码也不冒充旧 ZIP 的字节等价。

转换进程与游戏主进程同 UID，`:convert` 提供生命周期/崩溃隔离，**不是权限沙箱**。不声称抵御 root、恶意协作同 UID 进程或保证断电不会丢失所有缓存。

发布崩溃存在提交结果未知窗口。恢复会先重新核验真实选择，不凭 UI marker 猜测成功、不自动重复非幂等发布，也不把可能已经提交误报为回滚。旧准备资源选择改变时，legacy-epoch 屏障避免恢复陈旧原版选择。

## 构建与验证边界

- Android 9+/arm64，versionCode39；当前 targetSdk36。保持 `com.wmmt.fulldata60` 包名与已测旧版更新签名。
- APK 内只新增受审 Python/原生运行时代码、配方/哈希元数据和许可证，不装原版 `main`、PNG/TGA、字体、音视频、WPK/AO 或运行资源 ZIP。
- 运行时代码固定 CPython3.13.16、NumPy1.26.2、Pillow11；仅从签名 app 包提取并加载自身算法。job/来源目录不进入 Python 搜索路径。
- AO 数值 profile2 与 C ABI1 分开；固定 256/96，不降质量。主机证据不外推为 Android/bionic/libm 字节等价，设备端执行仍未验证。
- Java、Dex、压缩包成员/指纹、ELF/ZIP16KiB 对齐、主机有限测试与原始材料试转，不等于 Android SAF、通知、旋转、主进程死亡、长时取消、文件系统同步、GPU 或真机数值验收。
- MIT 仅覆盖相应移植/包装代码；原版派生物理代码/表仍需独立权利审查，不能宣传为全部版权清权。

## 开源第三方

APK 保留运行时内原许可证和 FFmpeg LGPL2.1+、OpenH264 BSD 等全文。另随候选提供 `OSS-Original-Converter-1.35.zip`，包含媒体库完整对应源、包装源/对象、许可证及离线构建/重链接材料；允许修改、调试和重链接，不提供或索取发行者私有签名密钥。完整官方源归档中的上游测试图像/音频不是游戏素材。此资料不是法律意见或专利授权保证。
