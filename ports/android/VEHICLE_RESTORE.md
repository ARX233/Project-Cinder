# 车身颜色、转子警告音与封路贴图还原

## 行为与边界

- 改装件菜单追加“车身颜色”入口，使用原版 11 色选择条、箭头、色板与原版字体。第十个改装类别是移植版对原版素材的组合，不宣称原机存在第十个类别。
- 原厂色与追加色分开存储：预览不写存档，返回丢弃预览，确认才更新当前车辆。按用户选择，直接开放有真实资源支持的原版追加色，不伪造更新卡次数。原厂色、车型、性能、物理和 RNG 不参与改色。
- 独立 `ccolor` 存档行位于对应 `own` 行之后。旧存档没有这一行时为原厂色；游客仅本次会话有效。换存档槽、新建和删除车辆清理临时选择。
- 套件画廊使用有界的逐视图缓存，按真实车型、原厂色、追加色、车身套件、贴纸、碳纤维和上下文绑定。绘制后恢复共用模型的纹理，不改变既有 Ghost 缓存。只处理本机玩家外观，不扩展 VS 网络协议或云端外观同步。
- R35/SpecV 保留原版不支持追加色的限制。未审核的隐藏前端别名 224..231 不进入既有 239 个 canonical 模型身份。38RS 缺少原版所需的 spec 贴图，不以猜测替代。可用选项以实际完整材质页为准。

## 原版证据对应

- 原机追加色是独立的 card+4 字节；card+0x166 是更新卡次数，不是里程或比赛次数。原版选择器最多展示十个追加色；本版直接开放是明确的移植策略。
- RX-7/FC/FD、RX-8 共用原版 `rx7_rev1.wav`。保留原生严格 `RevRate > float32(0.86)`、有效轮胎输入角绝对值小于 5 度及原生时间包络，不改成猜测的换挡一次性音效，也不修改物理回调。播放为 22000 Hz、局部音量系数 0.73；暂停静音保留相位，真实赛车序列开始/结束分别启动/停止循环。
- 封路箭头的原图是 DXT5，原机上传前执行 DEFAULT→OGL 压缩色序变换。新转换配方只对审核过的 course-arrow 对象启用这个步骤，保留 alpha、选择子、几何、材质和动画。不是蓝色改黄色的滤镜，旧通用解码器不变。

## 必须显式更新资源

新配置：`wmmt-main2e-source16-fma2-avc1-135-vehicle-restoration1`，13,991 个原始输入、1,800 个输出。新增真实原音和主资源成员 `player-body-paints.bin`，并更新十个路线箭头包。

请在新 APK 内从本人原版资源重新执行完整转换、确认选择新生成的资源。转换使用新的受控目录，不会原地改写旧资源 ZIP、发布树或存档。旧原版转换配置不被冒充为新配置；旧 prepared 数据仍保持旧资源事实，不能仅靠覆盖 APK 获得新音效/材质/箭头。缺少追加色数据时有可见更新提示。

玩家材质银行为独立 WPPAINT1：2,040 个键、6,080 个材质页描述，116,728,834 字节；SHA-256：

```
afaacb5b1b9a149c8ec78f32a1ff89da1173b9be99193fa0040ff693df498594
```

只从已选择的主资源根打开固定成员、流式核对编译时固定 SHA-256。没有第七个可选资源命名空间或新的 JNI 参数。只解码当前可见车身的页，不预载全部配色。

构建器拒绝源码树内影子头、错误哈希、符号链接、硬链接、FIFO 和读前/中/后身份变化，复制到新的 0700/0600 私有构建目录。生成头与原版图像、音频不纳入公共源码。

## 校验与未验证项

新 V6 元数据使用单独的审核入口；旧 V5/legacy 校验不放宽。APK 同时含多代 UI index 时不授权任何一代。严格新 APK 元数据门禁需要十一份独立参考，并校验 V5 的 98 张 sprite/18 个 ANM 前缀字节、原有 Builtin Ghost/轨迹/材质银行、新运行时和新主资源配置。

离线证据包括实际原版 WPK/VPK 的完整像素比较、材质作用域恢复、加载失败/上下文清理、完整原版 ANM 导入、菜单流和原音混音 CPU 测试。NDK 编译/链接、JDK 编译、APK 签名/结构审计必须分开报告；不能代替 Android GPU、实际扬声器或在线验证。

Android 打包的 Pillow 11 与本机转换环境不同，输出固定 SHA-256 不得为“跑通”而放宽；本任务未执行 Android 转换运行时。ASan 在当前 Apple 主机运行时未通过，不作为成功项；可用的 UBSan 与普通 CPU 测试单独计证。云端及设备/ADB/安装/唤醒测试继续暂停。
