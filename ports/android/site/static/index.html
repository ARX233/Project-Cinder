关于这套服务

成绩来源

成绩由客户端在正常计时赛完赛后提交，服务端只做格式与规则校验，不重放核验， 所以榜单标记为「社区成绩」。

鬼王规则

八个区域各有一个席位。击败当前联网鬼王后，服务器确认胜利录像并更新席位。

设备授权

设备 ID 在安装时生成，与应用更新无关。填进设备验证页即可自助开通， 也可由管理员代为批准。
